_Real-Time Zoom Poll Automation_

**Project Overview:**  
You are to build an automated poll generator for live Zoom meetings. The project simulates a real-time Zoom meeting automation tool that does the following:

1. **Transcript Capture (Simulation):** Every 15 minutes, the system captures the last 10 minutes of meeting transcript data. (For now, use a dummy transcript as a placeholder.)
2. **Poll Generation:** The captured transcript is processed by a local AI model (Ollama running Llama 3.2) to generate a poll—specifically, a question and four answer options formatted as JSON.
3. **Poll Posting:** The generated poll is then automatically posted into the live Zoom meeting UI (using the Zoom SDK). For testing purposes, you can simulate posting by outputting the poll to a custom UI component in your application.
4. **Custom UI & Automation:** Use the Zoom SDK to create a custom UI that can display the poll and simulate the meeting environment. The process runs with no human intervention.

# Real-Time Zoom Poll Automation

## Overview
This project is a proof-of-concept for automating poll generation during a live Zoom meeting. It simulates capturing a 10-minute transcript, generating a poll using a local instance of Ollama's Llama 3.2, and posting the poll into a simulated Zoom meeting UI every 15 minutes.

## Features
- **Transcript Capture Simulation:** Dummy transcript generator.
- **AI-Powered Poll Generation:** Uses a local Llama 3.2 model (via Ollama) to create poll questions and options.
- **Automated Poll Posting:** Simulated Zoom meeting integration with custom UI.
- **Completely Free:** All components are free/open-source for local testing.

## Setup Instructions
1. Clone the repository.
2. Install dependencies:
   - For Node.js: Run `npm install`
   - For Python: Run `pip install -r requirements.txt`
3. Configure your local instance of Ollama to work with Llama 3.2.
4. Run the project:
   - For Node.js: Run `node src/index.js`
   - For Python: Run `python src/main.py`

## Project Structure
- **src/**: Contains the source code for transcript simulation, poll generation, and Zoom integration simulation.
- **docs/**: Additional documentation and technical instructions.
- **.replit**: Configuration file for Replit.
- **README.md**: This file.

## Future Improvements
- Real integration with Zoom's live meeting SDK.
- Dynamic transcript capture from live audio.
- Enhanced UI for better interactive experience.
